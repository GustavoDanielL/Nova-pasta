📚 Documentação do Sistema

Guia completo de como utilizar o FinancePro

🎯 Visão Geral

O FinancePro é um sistema completo de gestão de empréstimos que permite controlar clientes, empréstimos, pagamentos e gerar relatórios detalhados.

👥 Gerenciamento de Clientes

  1. Adicionar Cliente: Clique no botão "+ Novo Cliente" e preencha os dados obrigatórios (nome, CPF/CNPJ, telefone e e-mail).
  2. Buscar Cliente: Use a barra de pesquisa para filtrar clientes por nome, CPF ou telefone.
  3. Visualizar Empréstimos: Clique no ícone "💰" na linha do cliente para ver todos os seus empréstimos.

💰 Empréstimos

  1. Criar Empréstimo: Clique em "+ Novo Empréstimo", selecione o cliente, valor, taxa de juros e prazo.
  2. Acompanhamento: O sistema calcula automaticamente o valor das parcelas e exibe o status (Em dia, Atrasado, Quitado).
  3. Detalhes: Clique em um empréstimo para ver todas as parcelas e histórico de pagamentos.

💳 Pagamentos

  1. Registrar Pagamento: Selecione o empréstimo e informe o valor recebido.
  2. Tipos de Pagamento:
    • Parcela Completa: Valor da parcela mensal normal
    • Parcial: Qualquer valor diferente da parcela
    • Quitação: Pagamento total do saldo devedor
  3. Histórico: Todos os pagamentos ficam registrados com data e valor.

📊 Relatórios e Exportação

  1. Relatório Geral: Visão completa de todos os empréstimos e estatísticas.
  2. Empréstimos Atrasados: Lista detalhada com dias de atraso e contato dos clientes.
  3. Exportar Dados: Exporte para CSV (Excel) ou JSON (backup completo).
  4. Backup Manual: Nas Configurações, faça backup de segurança dos dados.

🔔 Alertas e Notificações

O sistema exibe alertas automáticos para:

  • Empréstimos com parcelas vencidas
  • Parcelas próximas do vencimento (5 dias)
  • Status de pagamentos atrasados

Clique no ícone de sino 🔔 no cabeçalho para ver todos os alertas ativos.

⚙️ Configurações

  1. Tema: Alterne entre modo claro e escuro conforme sua preferência.
  2. Backup Manual: Exporte uma cópia de segurança de todos os dados.
  3. Segurança: Sempre faça logout ao terminar de usar o sistema.

💡 Dicas de Uso

  • Use a pesquisa global (canto superior direito) para encontrar rapidamente clientes ou empréstimos.
  • Acompanhe o Dashboard diariamente para ver o status geral dos empréstimos.
  • Faça backups regulares dos seus dados (recomendado semanalmente).
  • Utilize os filtros na aba de Empréstimos para visualizar apenas ativos, atrasados ou quitados.
  • Pressione Ctrl+Shift+R para recarregar a interface caso necessário.

❓ Suporte

Em caso de dúvidas ou problemas, verifique:

  • Se o backend está rodando corretamente (porta 8000)
  • Os logs do sistema no console (F12)
  • Se todos os campos obrigatórios foram preenchidos corretamente
